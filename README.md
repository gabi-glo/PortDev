📁  Projeto Portfólio Dev 
Um portfólio profissional moderno e responsivo para desenvolvedor full stack, construído com HTML5 e CSS3 puro.Projeto faz parte da formação full stack da Rocketseat.

✨ Funcionalidades
✅ Design Responsivo - Adaptável para mobile, tablet e desktop

✅ Seção Hero com introdução profissional

✅ Portfólio de Projetos em grid interativo

✅ Seção de Serviços com cards destacados

✅ Contato Integrado com redes sociais

✅ Animações Suaves em hover effects

✅ Performance Otimizada com CSS puro
